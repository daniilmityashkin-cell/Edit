# SFX — звуки для текста

Папка `sfx/<категория>/*.wav` — библиотека NOIR CAPTIONS. Подпапка = категория.
Своя библиотека (не попадает в Git): `%APPDATA%\NOIR Captions\sfx\<категория>\` (кнопка «Папка SFX» в панели).

| Категория | Для чего (авто-подбор по вылету) |
|---|---|
| whoosh | слайды, Whip, Rotate, Zoom |
| pop | Pop, Grow, Blur Pop |
| hit | Slam, Punch |
| click | жёсткая смена без анимации |
| shimmer | Fade (блеск) |
| morph | Blur (смена слова) |
| counter | счётчик/числа (ставится вручную: «В текущее время») |
| blur_out | выход Fade/Blur |
| scale_down | выход Shrink/Zoom/Slam |
| rise | нарастание (вручную) |
| glitch | глитч (вручную) |

Форматы: wav, mp3, aif, aiff, m4a. Файлы в категории чередуются по кругу.

## Свои звуки главнее базовых
Папка пользователя: `%APPDATA%\NOIR Captions\sfx\` (кнопка «Папка SFX»). Можно класть:
- файлы в подпапку-категорию: `shimmer\мой_блеск.wav`;
- **целый пак как есть** — категория определяется по имени файла: `text_shimmer`, `morph`, `counter`, `blur_out`,
  `title_scale_down`, `whoosh`, `pop`, `hit`/`impact`, `click`/`tick`, `riser`, `glitch` (а также «блеск», «счётчик», «уход в блюр»…);
  нераспознанные файлы попадают в категорию по имени папки (их можно выбрать вручную).
Если у категории есть ваши звуки, используются **только они**; галочка «Подмешивать базовые звуки к своим» добавляет базовые.
В списке «Звук» ваши помечены ★.

## Стартовый набор
Звуки `*.wav` в этой папке сгенерированы скриптом `generate_sfx.py` (простой синтез, без чужих сэмплов — права
не ограничены). Характер (яркие «воздушные» эффекты: блеск с искрящимся хвостом, взмах-смена слова, тики счётчика,
нарастающий «уход в блюр», «масштаб вниз») подобран по спектру демо-ролика с SFX-паком; центры спектра совпадают с роликом
в пределах ~15%, но это не копия и не тот же тембр. Для точного звучания кладите свои паки в папку пользователя. Пересоздать стартовый набор: `python sfx/generate_sfx.py` (нужен numpy).
