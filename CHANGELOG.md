# Changelog

## 0.44.0 — 2026-11-09 · Тише: одна золотая кнопка на экран
- **Правило:** золото — только там, где действие: одна главная кнопка на экране, активная вкладка, включённый переключатель. Блик проходит по золоту только под курсором, сам по себе ничего не мерцает.
- **Без рамок:** карточки, поля, кнопки и списки — ровные тёплые чёрные плоскости без обводок, градиентов и свечений. Заголовки разделов — маленькие приглушённые прописные вместо золотого текста. Фокус — тонкая линия.
- **Первый экран — одно действие:** заголовок, строка, кнопка «Распознать речь», язык и качество. Устройство, два спикера, термины, импорт и пакет — под «Дополнительно». Когда всё готово, плашка готовности не показывается (проблемы видны, как раньше).
- **Настройки — список:** разделы свёрнуты до названия и раскрываются по клику (панель помнит, что открыто); «Файлы» на странице текста — тоже. Переход из радиального меню сам раскрывает нужный раздел.
- **Одна главная кнопка:** на странице «Текст» она внизу (создать / обновить), в шапке не дублируется.
- **Шапка и вкладки:** логотип меньше и без свечения, статус — точка и слова без плашки, вкладки — только слова (иконки возвращаются в узкой панели).
- **Радиальное меню и помощник:** без номеров, узлов и свечений; лист раздела и окно помощника — без рамок; сообщения — спокойные, золотая только кнопка «Применить / Спросить».

## 0.43.0 — 2026-11-07 · Помощник: больше готовых команд, скрипты чинят себя, «что ты умеешь»
- **Вид текста готовыми командами (и без ИИ):** «акценты красным», «текст белый», «цвет #ffcc00», «чёрная обводка 4», «без обводки», «убери тень», «капсом», «строчными», «свечение акцентам», «шрифт Montserrat (для акцентов)». Цвета по названию (рус/англ) и #hex; шрифт — ближайшее установленное семейство, для слов SemiBold/Bold, для акцентов ExtraBold/Black. Готовые субтитры сразу перекрашиваются.
- **Скрипты исправляют себя:** код сначала компилируется в AE без запуска (ошибки синтаксиса ловятся до «Применить»); запрещённое и синтаксис ИИ переписывает до 2 раз; если скрипт упал в AE — ИИ получает свой код и ошибку и показывает исправленный вариант (до 2 раз).
- **«Что ты умеешь?»** — первая подсказка в помощнике: все возможности по темам, каждый пример — кнопка, которая его выполняет.

## 0.42.0 — 2026-11-07 · Автозум, два спикера, стиль из видео, пакет
- **Автозум (Правка → Автозум, помощник: «автозум на акцентах»):** видео приближается на 105/110/115% — на каждом акценте (и назад после слова), на фразах через одну или на кусках нарезки (чередование, классический джамп-кат). Резкий толчок за кадр или плавно; к лицу, если оно найдено (без скачка картинки). «Убрать» возвращает 100%.
- **Два спикера (Текст → «Два спикера — разные цвета»):** после распознавания фразы делятся по голосу (тембр и высота голоса, на этом компьютере, только numpy); второй голос — своим цветом (Настройки → Раскладка). Если второго голоса нет — фразы не красятся. Ошибку исправляет кнопка «Голос 1/2» у фразы (с отменой).
- **Стиль из видео (Стиль → «Стиль из видео», помощник: «стиль как в референсе»):** панель находит в ролике отрисованные субтитры (ровные строки однотонных букв, которые меняются) и меряет высоту, размер, цвета, капс, слов на экране, обводку и появление (жёсткая смена / проявление / влёт из крупного / pop). Берётся ближайший встроенный стиль, замеры кладутся в него, результат сохраняется как свой стиль и выбирается. Нужен OpenCV (как для поиска лица).
- **Пакетом: несколько композиций (Текст, помощник: «обработай выделенные композиции»):** выделите композиции в Project — в каждой по очереди распознаётся самый длинный слой со звуком и создаются субтитры в текущем стиле (с исправлениями слов из памяти). Ошибка одной не останавливает остальные; «Отменить» останавливает пакет.
- **Нарезка двигает остальные слои:** музыка, звуки и графика сдвигаются за вырезанным (каждый — на вырезанное до его начала), сами не режутся; заблокированные не трогаются.
- **Иконка панели** в AE — золотая «N». **Светлая тема AE** подогнана под чёрно-золотой дизайн. Уведомления — тёмные с золотой кромкой.

## 0.41.0 — 2026-11-07 · Чёрно-золотой дизайн
- **Новая палитра:** тёплый чёрный лак вместо серого AE и полированное золото вместо синего (светлая тема AE — светлая, с тёмным золотом). Главные кнопки — золотой металл, по которому время от времени проходит блик; заголовки карточек — золотым градиентом; переключатели и ползунки — золотые.
- **Свой логотип:** чёрный диск в золотом ободке, внутри сегментированное золотое кольцо и «N» — хромированные стойки и золотое лезвие-диагональ, по которому пробегает блик.
- **Шар помощника:** чёрная стеклянная сфера в вращающемся золотом ободке, внутри медленно переливается янтарный свет, сверху стеклянный блик; когда панель занята — ободок крутится быстрее. В центре радиального меню и в шапке помощника.
- **Радиальное меню по мотивам круговых интерфейсов:** тёмное кольцо из золотых сегментов (свет → золото → бронза по кругу), выбранный сегмент загорается и получает яркую дугу снаружи, номера 01–08 внутри кольца, тонкий внешний круг с узлами и название раздела, написанное по дуге; янтарное свечение поворачивается к выбранному разделу. Панель действий — чёрный лак с золотой кромкой, наведение — золото с бликом.

## 0.40.0 — 2026-11-07 · Любые просьбы скриптом (эксперимент)
- **Помощник выполняет просьбы, для которых нет готовой команды:** ИИ пишет скрипт для AE, код показывается в плане и запускается только после «Применить» — одной отменой. Включается в помощнике: «ИИ-модель» → «Любые просьбы — скриптом»; «скрипт: …» — сразу код.
- **Проверка перед запуском в AE:** файлы, сеть, системные команды, eval, сохранение, рендер, импорт, диалоги, служебные объекты панели, бесконечные циклы и синтаксис новее ES3 не запускаются; ИИ один раз просят переписать. Переменные панели скрипту недоступны.
- Отдельная модель для кода (например, qwen2.5-coder:7b); принятый скрипт запоминается с кодом.
- Честно: это защита, а не песочница — код нужно смотреть; хитро зациклившийся скрипт может подвесить AE.

## 0.39.0 — 2026-11-07 · Память помощника
- **Помощник учится на ваших исправлениях слов:** при создании субтитров запоминает замены, похожие на ошибку распознавания (опечатка или транслит: «нуар → NOIR»), и после следующего распознавания подставляет их сами, а написание передаёт Whisper подсказкой. Смысловые замены и переписанные строки не запоминаются; отмена подстановки учит обратному.
- **«Запомни: …» / «забудь …» / «что ты помнишь»:** заметки-предпочтения уходят ИИ в каждой просьбе; «запомни: X пишется Y» — сразу исправление слова.
- **Принятые ответы ИИ повторяются из памяти:** та же просьба в следующий раз сразу даёт план — даже без ИИ; последние ответы ИИ видит как примеры.
- **Настройки → Память помощника:** список запомненного с удалением по одной записи, «Очистить память», переключатель обучения. Всё хранится только на этом компьютере.

## 0.38.0 — 2026-11-07 · Нарезка видео по речи и стиль Street Talk
- **Помощник режет видео по словам:** «убери паузы (длиннее X с)», «вырежи паразитов из видео», «оставь с 5 по 20 с», «нарежь по фразам». Сначала план с замером «было → стало» (секунды, сколько кусков, какой слой), режет только после «Применить» — одной отменой в AE. Куски встают встык, слова переезжают на новое время, слова из вырезанных мест убираются, субтитры пересоздаются. Режется выделенный слой (можно видео и звук вместе), без выделения — распознанный, повторно — куски прошлой нарезки. Прослушивание и поиск лица после нарезки берут кадры из исходника по карте кусков.
- **Стиль Street Talk** (по референсу уличного интервью): белые жирные слова заглавными по центру, появляются жёсткой сменой точно на слове, по 1–3 слова; акценты (*звёздочки*) — красный жирный курсив вдвое крупнее на своей строке, влетают из крупного размытого за 4 кадра (новая анимация «Zoom Blur»).
- Честно: звуки, музыка и прочие слои при нарезке не сдвигаются; Time Remap не поддерживается.

## 0.37.0 — 2026-11-07 · Радиальное меню: действия в одной панели, чёткий текст
- **Действия раздела теперь всегда в одном месте:** стеклянная панель справа от кольца (кольцо и панель вместе по центру), а в узкой панели — под кольцом. В шапке — иконка и название раздела, ниже ровная сетка кнопок с номерами клавиш; текущий выбор отмечен. При смене раздела панель стоит на месте, меняется только содержимое (мягкая смена); появление — короткий сдвиг с затуханием.

- **Шрифт интерфейса — системный Segoe UI** на Windows (AE рисует его чётче), Inter — запасной.

## 0.36.0 — 2026-11-07

## 0.35.0 — 2026-11-07 · Аккуратное радиальное меню и автоисправление замечаний
- **Второе кольцо радиального меню — одна стеклянная карточка** рядом с выбранным кружком: ровный список одинаковых строк (длинные списки — в две колонки), номер клавиши справа, отмеченное сейчас — синей точкой. Карточка раскрывается от своего кружка с лёгкой пружиной, строки появляются друг за другом; никогда не задевает другие кружки и центр.
- **«Исправить автоматически»** в блоке «Перед созданием»: текст ставится в безопасную зону выбранного формата (высота, ширина строки, при необходимости размер), отсутствующий шрифт заменяется на установленный из списка стиля. Если замечаний не осталось — создание продолжается само. Скорость чтения и очень длинные слова честно остаются ручными.
- Замечания больше не повторяются по несколько раз для одной фразы.

## 0.34.0 — 2026-11-07 · Помощник выделяет слои, делает маски и готовит Roto Brush
- **Выделение:** «выдели субтитры / акценты / обычные слова / эту фразу / видео / пульт», «сними выделение» — помощник сам выделяет слои в таймлайне.
- **Маски:** «маска круг мягкая», «маска на верхнюю половину», «виньетка», «маска снаружи» — овал или прямоугольник в нужной части слоя (выделенного или видео), растушёвка, инверсия; с ИИ — любые размеры словами.
- **«Вырежи человека» / Roto Brush:** помощник делает копию видео над субтитрами, выделяет её и открывает в окне слоя — остаётся один раз обвести человека кистью Roto Brush (Alt+W) и нажать Freeze. Сам обвести кистью он не может: After Effects не даёт скриптам управлять Roto Brush. «Поставь субтитры за человеком» без выделения теперь берёт эту копию.

## 0.33.0 — 2026-11-07 · Помощник работает с текстом, пульт в AE, английский, вид панели
- **Помощник правит текст.** «Убери слова-паразиты» (ну, ээ, типа, как бы, um, uh, you know…) — остальные слова сохраняют точный тайминг. «Добавь эмодзи» — эмодзи приклеивается к ключевому слову, тайминги не меняются (без ИИ — по словарю, с ИИ — модель выбирает слово). «Исправь ошибки» (с ИИ) — принимаются только строки с тем же числом слов, поэтому тайминги точные; остальные пропускаются с пометкой. «Переведи на английский / испанский / …» (с ИИ, 14 языков) — начало и конец каждой фразы сохраняются, слова внутри распределяются по длине. «Сделай динамичнее / спокойнее» — план из настроек анимации и обновление субтитров.
- Перед применением помощник показывает **«было → стало»** по строкам; AE меняется только после «Применить». Любая текстовая правка помощника отменяется одной кнопкой «Отменить правку». Если субтитры уже созданы, после применения они обновляются.

- Ручной сдвиг фразы (мышью или панелью) сохраняется при «Обновить фразу» и «Обновить все фразы».
- Новая основная вкладка **«4 · Правка»** (и раздел «Правка» в HTML-панели): что менять — субтитры этого видео /
  выделенные слои / все NOIR; положение (вверху / по центру / внизу — фраза целиком), сдвиг стрелками на N px,
  «Вернуть на исходные места», смена появления и исчезания, «Применить текущий стиль» (акцентам — стиль акцента),
  «Удалить субтитры».
- HTML-мост: JSON собирается только для изменившихся элементов скрытой панели (в Node ~4,7× меньше работы на действие).
