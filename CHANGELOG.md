# Changelog

## 0.5.1 — 2026-10-29
- Исправлено: слои получали шрифт, которого нет в системе (AE принимает любое имя) → окно Resolve Fonts и «обычный» вид.
  Теперь наличие шрифта проверяется до назначения; из цепочки берётся первый установленный, иначе оставляется
  шрифт по умолчанию с предупреждением.
- Исправлено: `short` — зарезервированное слово ExtendScript (ошибка загрузки); добавлена проверка ES3 в тестах.

## 0.5.0 — 2026-10-29
- Анимация: сетка вылетов в 1–2 клика (Slam, Whip, Rotate, Grow, Blur Pop и др.), применяется сразу к выделенным слоям.
- Режим наложения и прозрачность текста (инверсия = Difference), кнопка «◐ Инверсия», пресет Invert.

## 0.4.1 — 2026-10-29
- Пресеты по референсам переделаны: размеры, цвета и положение сняты с кадров роликов; добавлены
  Kinetic Orange и Editorial Italic; SF Pro добавлен в запасные шрифты.

## 0.4.0 — 2026-10-29
- Вкладка «Слои»: «★ Сделать акцентом» / «Сделать обычным», применение шрифта, размера, цвета, обводки,
  эффектов и анимации к выделенным слоям (по отдельности, к одному или ко всем сразу); «Шрифт → выделенным слоям».
- Компактная панель: кнопка «Создать субтитры» и статус закреплены сверху; вкладки сжаты.
- Авто-акценты (главное слово во фразе).
- Тёмная тема панели, свои вкладки и кнопки (с откатом на обычный вид при ошибке).
- Исправлено зависание AE при распознавании на Windows (запуск Python через `File.execute`).
- Проверка наличия модели (`model.bin`), `recognition/download_model.py` для скачивания с прогрессом.
- Документация: INSTALLATION, TROUBLESHOOTING, TESTING, LICENSES.

## 0.3.0
- Пресеты стилей по референсам (Kinetic Stack, Editorial, Reels Glow, NOIR Red), пословная сборка фразы,
  акценты `*слово*`, разрыв `|`, тень и свечение, blur-анимации, сохранение своих пресетов.

## 0.2.0
- Панель ScriptUI с вкладками, локальное распознавание faster-whisper (GPU/CPU), правка текста,
  группировка слов, анимации появления/исчезновения.

## 0.1.0
- Первый скрипт: текстовые слои по словам с анимацией, архитектура.
