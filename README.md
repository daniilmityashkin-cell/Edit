# NOIR CAPTIONS

Локальный генератор анимированных субтитров для Adobe After Effects.
Распознавание речи на своём компьютере, без платных API, результат — редактируемые текстовые слои AE.

## Статус

| Этап | Что | Статус |
|---|---|---|
| 0 | Архитектура | [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) |
| 1 | Скрипт AE: слои + анимация | ✅ проверено в AE (7 слоёв, тайминги верные) |
| 2–3 | Панель + распознавание + связка | код готов, тесты в Node проходят, **ждёт проверки в AE на Windows** |
| 5–6 | Пресеты стилей по референсам, акценты, пословная сборка | код готов, 144 теста в Node, **ждёт проверки в AE** |

## Установка (Windows, один раз)

1. **Python 3.12** — https://www.python.org/downloads/ (при установке галочка *Add python.exe to PATH*).
2. **Движок распознавания** — в PowerShell из папки проекта:
   ```
   powershell -ExecutionPolicy Bypass -File recognition\setup_windows.ps1
   ```
   Создаст `.venv` внутри проекта и поставит faster-whisper (+ CUDA-библиотеки для NVIDIA).
   Модель не качает. В конце должно быть `CUDA устройств: 1`.
3. **Панель в AE** — PowerShell **от имени администратора**, из папки проекта:
   ```
   powershell -ExecutionPolicy Bypass -File scripts\install_panel.ps1
   ```
   (или вручную скопируйте `ae\NOIR Captions.jsx` в
   `C:\Program Files\Adobe\Adobe After Effects <версия>\Support Files\Scripts\ScriptUI Panels\`)
4. AE → `Edit → Preferences → Scripting & Expressions` → включить
   **Allow Scripts to Write Files and Access Network** (нужно, чтобы запускать Python; в сеть панель не ходит).
5. Перезапустить AE → `Window → NOIR Captions.jsx`. Панель пристыковывается как любая другая.

После `git pull` переустанавливать панель не нужно — она грузит код из папки проекта
(путь к ней спросит один раз).

## Работа

1. **Речь**: выделите в таймлайне слой со звуком (аудио или видео) → «Распознать речь».
   Распознаётся только видимая часть слоя. AE не зависает — статус и прогресс в панели.
   Первый запуск модели спросит разрешение на скачивание (large-v3 ≈ 3 ГБ, один раз).
2. **Текст**: исправьте ошибки. Одна строка = одна фраза; слова правьте внутри строк —
   тайминги сохранятся. Разметка:
   - `*слово*` или `*два слова*` — **акцент** (свой шрифт/размер/цвет/свечение, отдельная строка);
   - `|` — начать новую фразу с этого места.
   Можно сохранить/открыть JSON, чтобы не распознавать заново.
3. **Стиль** (пресет, шрифт) и **Вид** (размер, цвет, обводка, тень, свечение) — настройки отдельно для обычных и акцентных слов: шрифт (поиск по
   установленным или «взять с выделенного текстового слоя»), размер, цвет, обводка, КАПС, тень, свечение.
   «Сохранить…» — свой пресет (хранится в папке пользователя, не в git).
4. **Раскладка**: слова по очереди / фраза целиком, слов на экране, символов в строке, позиция, интервалы.
5. **Анимация** — сетка вылетов (17 на вход, 14 на выход: Fade, Blur, Blur ↑, Pop, Punch, Slam, Whip, Rotate, Grow, Blur Pop, сдвиги, Zoom…).
   Переключатель «Вход / Выход», клик по плитке: если выделены текстовые слои — вылет сразу применяется к ним, иначе запоминается для новых субтитров.
   **Инверсия и прозрачность**: вкладка «Вид» → «Режим» (Инверсия/Difference, Exclusion, Overlay…) и «прозр. %»;
   на вкладке «Слои» кнопка «◐ Инверсия» включает и выключает инверсию у выделенных слоёв (хоть у одного).
   Инверсия отдельных слов при создании: в тексте `~слово~` (можно вместе с акцентом: `*~слово~*`).
6. **Слои** — правка уже созданных (и любых своих текстовых) слоёв: выделите слои в таймлайне →
   «★ Сделать акцентом» / «Сделать обычным», либо «Применить к выделенным» (вид и/или анимация из панели).
   Выделили все слои — изменятся все. Позиция и тайминг слоя не меняются.
   Свойства применяются по отдельности (шрифт / размер / цвет / обводка / эффекты / анимация): отметьте нужное.
   Разные шрифты на разные слои: выберите шрифт на вкладке «Стиль» и нажмите «Шрифт → выделенным слоям».
7. **Создать субтитры** — слои `NOIR · …` (зелёная метка, акценты — другая). Повторное создание заменяет только их.
   Отмена — один `Ctrl+Z`. Если аудиослой сдвинуть после распознавания — субтитры встанут по новому месту.

### Язык
По умолчанию **Русский**. Внимание: если в ролике английская речь, а язык стоит «Русский»,
модель **переводит** её на русский (проверено). Для англ./смешанных роликов выбирайте «Авто» или «English».

## Тесты

```
node tests/run_tests.js
```
91 тест на имитации AE: группировка, правки текста, все сочетания анимаций (ключи не выходят
за слой), повторная генерация, шрифты, панель. Сквозной тест с настоящим Python:
```
set NOIR_PYTHON=.venv\Scripts\python.exe
set NOIR_MEDIA=C:\path\to\clip.mp4
node tests/run_tests.js
```
Имитация не заменяет проверку в настоящем AE.

## Числа перетаскиванием
Все числовые поля (размер, позиция, длительности, громкость…) работают как в After Effects: **зажмите левую кнопку на числе и
двигайте мышь влево/вправо**. **Shift** — точнее (÷10), **Ctrl/Alt** — быстрее (×10). **Простой клик** по числу — ввести значение
вручную. Границы у каждого поля свои. Если курсор ушёл за край поля и значение перестало меняться — отпустите и возьмитесь снова.

## SFX (звуки)

Вкладка **SFX**. Включите «Озвучивать при создании субтитров» — при «Создать субтитры» звуки ставятся сами:
- **Появление / Акцент / Выход**: «Авто (по анимации)» (Pop → поп, Slam → удар, Whip → вжух, Blur → смена слова, Fade → блеск…),
  «Выкл» или конкретная категория; акцент может звучать иначе («Как появление» по умолчанию).
- **Громкость, дБ**, **разброс** (случайно ± дБ, повторяемый), **мин. интервал** (близкие звуки пропускаются, акцент главнее).
- **Озвучить выделенные слои** — добавить звуки к выделенным текстовым слоям; **В текущее время** — вставить выбранный звук туда,
  где стоит индикатор времени (счётчики, нарастания, глитчи); **Убрать SFX** — удалить звуковые слои `NOIR SFX · …`.
Звуки — отдельные слои под текстом, их можно двигать в таймлайне. Библиотека: `sfx/` (базовый набор синтезирован под
характер референсов, см. `sfx/README.md`) и **ваша папка** `%APPDATA%\NOIR Captions\sfx\` (кнопка «Папка SFX»): ваши звуки
главнее базовых, категория определяется по подпапке или по имени файла (`text_shimmer`, `blur_out`, `title_scale_down`…),
ваши помечены ★; «Подмешивать базовые звуки к своим» добавляет базовые.

## Функции (вкладка «Функции»)

Отдельные инструменты, работают независимо от распознавания.
- **Счётчик**: индикатор времени ставите куда нужно → «Создать счётчик». Настройки: от/до, длительность, шаг, интервал
  обновления (0.1 с = десять смен в секунду), ход (замедление/линейно/ускорение/плавно), знаки после запятой, нули,
  разделители тысяч, приставка и суффикс (`$`, ` K`, `%`), позиция, «Акцент/Обычный» вид и размер, звук `counter`.
  Число считает выражение в Source Text слоя — слой можно двигать и обрезать, выражение видно в AE.
- **Зачёркивание**: выделите слова (текстовые слои) → «Зачеркнуть». Полоса «вытирается» слева/справа/от центра,
  наклон, смещение, толщина, цвет; уходит вместе со словом. «Убрать зачёркивания» удаляет только свои полосы.
- **Маска**: выделите текстовые слои + один видео/фото слой → видео окажется внутри букв (копия слоя под текстом, Alpha Matte).
  «Вырез» — буквы прозрачны. «Убрать маски» удаляет подложки и возвращает видимость тексту.
- **По буквам**: на вкладке «Анимация» плитки Letters Fade/Rise/Pop/Blur и Type (текстовые аниматоры AE).
- **Автоперекладка**: после «Сделать акцентом/обычным» слова фразы заново встают по правилам раскладки; отдельно — «↻ Перекласть фразу».

## Размер окна

Размер панели задаёт AE: растяните её рамку один раз, AE запомнит. Кнопка «Создать субтитры» и статус
закреплены над вкладками и видны при любой высоте; вкладки компактные (около 300 px по высоте).

## Дизайн панели

Тёмная тема в `ae/noir/theme.jsx`: чёрный фон, один оранжево-красный акцент, свои вкладки и кнопки.
ScriptUI не умеет градиенты, размытие и скруглённые карточки, а нативные поля ввода/списки не перекрасить.
Полноценный «стеклянный» дизайн как в референсах возможен только в HTML-панели (CEP/UXP) — отдельный этап.
Если тема не загрузилась, панель работает в обычном виде.

## Известные ограничения

- Слой-прекомпозиция, Time Remap и обратная скорость пока не поддерживаются (будет понятная ошибка).
- Многословные группы — один слой на группу; пословное появление внутри группы — следующий шаг.
- Проверка наличия шрифта и список шрифтов — только AE 24+; в старых версиях — ввод PostScript-имени.
- Если имя пользователя Windows на кириллице — возможны проблемы с путём к временной папке (сообщите).

## Пресеты (`presets/styles/*.json`)

| Пресет | Референс | Что |
|---|---|---|
| Kinetic Blue | риелтор-парень | мелкие слова оранжевым строчными, главное — огромное голубое капсом, строки вплотную, снизу + blur |
| Kinetic Orange | то же | белые слова + оранжевый акцент |
| Editorial | риелтор-девушка | мелкий белый текст + огромная фиолетовая антиква Didone капсом, blur |
| Editorial Italic | то же | курсивная антиква белым + акцент жирной антиквой |
| Invert | риелтор-парень (инверсия) | белый текст в режиме Difference: инвертирует кадр под буквами, blur-pop |
| Mix Colors | парень на набережной | слова ступенькой, главные крупные и каждое своего цвета по кругу (синий/красный/зелёный/оранжевый) |
| Pop Words | девушка-интервью | по одному слову по центру белым, выделенные — розовый жирный курсив |
| Reels Glow | ремонт в Дубае | белый мелкий текст в 1–2 строки, акцент красным со свечением, pop |
| NOIR Red | доктор | одно слово, красная антиква, жёсткая смена |

Шрифты в пресетах — бесплатные Google Fonts (Montserrat, Inter, Bodoni Moda / Playfair Display)
с запасными: SF Pro, Segoe UI, Arial, Georgia, Times (берётся первый найденный в системе). Для точного вида установите:
https://fonts.google.com/specimen/Montserrat , /Inter , /Bodoni+Moda , /Playfair+Display.
Шрифты в оригинальных роликах не определены точно — пресеты передают характер, а не копируют пиксель в пиксель.

Пока не сделано из референсов: плашка под числом («58K»), градиентная заливка,
пословная смена цвета внутри строки при произнесении, текст за человеком (нужна ротоскопия).
