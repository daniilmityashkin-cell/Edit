# NOIR CAPTIONS

Локальный генератор анимированных субтитров для Adobe After Effects.
Распознавание русской речи на своём компьютере, без платных API, результат — редактируемые текстовые слои AE.

## Этап 1: как проверить

1. Скачайте/склонируйте репозиторий (ветка `noir-captions-stage1`).
2. After Effects → откройте любую композицию (или ничего — скрипт создаст тестовую 1080×1920).
3. `File → Scripts → Run Script File…` → `ae/scripts/noir_stage1_test.jsx`.
4. Выберите пресет (`Cut`, `Pop`, `Rise`) → «Создать».

Что должно получиться:
- 7 текстовых слоёв `NOIR · …`, каждое слово появляется в своё время (0.2–4.2 с);
- текст красный, капсом, вверху кадра, по центру;
- для `Pop`/`Rise` на слоях есть ключи Opacity/Position/Scale;
- повторный запуск заменяет **только** слои `NOIR · …` (помечены в комментарии слоя), ваши слои не трогаются;
- `Ctrl+Z` один раз — откатывает весь запуск.

Если что-то не так — пришлите текст алерта/ошибки и версию AE (`Help → About`).

## Примеры стилей

`*.mp4` в корне — референсы. Стиль из `1774639922519426331.mp4`: одно слово, капс, узкая контрастная антиква (Didone condensed), красный, верх кадра, жёсткая смена без анимации, текст частично за головой героя (это ротоскоп/маска — автоматизировать будем отдельно, позже).
