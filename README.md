# NOIR CAPTIONS

Локальный генератор анимированных субтитров для Adobe After Effects.
Речь распознаётся на вашем компьютере (faster-whisper, без платных API и без отправки аудио), результат — редактируемые текстовые слои AE.

## Панель (0.32)

Одна HTML-панель: **Window → Extensions (Legacy) → NOIR Captions**. Четыре вкладки, всё лишнее — в «расширенном режиме».

- **Текст** — весь путь по порядку:
  1. **Распознавание.** Панель сама проверяет, готов ли компьютер (движок, модель, доступ к файлам, шрифты стиля), и даёт кнопки «Установить» и «Скачать» — без ручного PowerShell. Выделите слой со звуком → «Распознать речь». Можно открыть JSON или SRT/VTT.
  2. **Текст.** Одна строка — одна фраза. Выделите слово: *Акцент*, *Перенос*, *Разделить* (тайминги сохраняются).
  3. **Тайминг слов.** Слова фразы на шкале времени: тяните края мышкой, само слово — сдвиг; клик — к слову в AE; двойной клик — исправить слово. Неуверенно распознанные — пунктиром.
  4. **Создать / Обновить фразу / Превью / Проверить**, экспорт SRT/VTT.
- **Стиль** — галерея с живым превью анимации при наведении, избранное ★; стили без установленных шрифтов помечены и стоят в конце. Размер, положение, появление слов (по словам / фразой / караоке), формат и безопасная зона Reels/TikTok/Shorts/1:1/16:9.
- **Правка** — уже созданные субтитры: положение, сдвиг, размер, «убрать с лица», «за человеком», время, анимация, стиль, акцент, инверсия, удаление. Каждое действие — один Ctrl+Z.
- **Настройки** — распознавание, шрифт (поиск по установленным), вид текста, раскладка, язык RU/EN, расширенный режим, журнал.
- **Кнопка-шар** слева вверху (или правая кнопка мыши, или Пробел) — радиальное меню: до 8 действий по ситуации, клавиши 1–8. Центр меню — **помощник** (просьбы своими словами через локальную модель Ollama, `docs/ASSISTANT.md`; сначала показывает план, AE меняется только после «Применить»).

Панель следует теме AE (светлая/тёмная), один акцент — синий с белым, иконки Lucide.

## Установка (Windows, один раз)

1. **Python 3.12** — https://www.python.org/downloads/ (галочка *Add python.exe to PATH*).
2. **Панель** — PowerShell в папке проекта:
   ```
   powershell -ExecutionPolicy Bypass -File scripts\install_cep_dev.ps1
   ```
   Скрипт копирует панель, включает режим разработчика CEP и убирает загрузчик старой ScriptUI-панели, если он был установлен.
3. AE → `Edit → Preferences → Scripting & Expressions` → **Allow Scripts to Write Files and Access Network** (нужно для запуска Python; в сеть панель не ходит).
4. Перезапустите AE → **Window → Extensions (Legacy) → NOIR Captions**. На вкладке «Текст» нажмите **«Установить»** (движок распознавания, ~1 ГБ) и **«Скачать»** (модель) — откроется окно с прогрессом, панель сама увидит, когда всё готово.

После `git pull` снова запустите `scripts\install_cep_dev.ps1` и перезапустите AE.

Подробнее: [docs/INSTALLATION.md](docs/INSTALLATION.md), устройство: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), панель: [docs/HTML_PANEL.md](docs/HTML_PANEL.md).

## Разметка текста

- `*слово*` или `*два слова*` — акцент (свой шрифт, размер, цвет);
- `~слово~` — инверсия слова (Difference);
- `|` — новая фраза с этого места; `↵` — перенос строки.

## Известные ограничения

- Слой-прекомпозиция, Time Remap и обратная скорость пока не поддерживаются (будет понятная ошибка).
- Проверка наличия шрифта и список шрифтов — только AE 24+; в старых версиях — ввод PostScript-имени.
- Если имя пользователя Windows на кириллице — возможны проблемы с путём к временной папке (сообщите).

## Пресеты (`presets/styles/*.json`)

| Пресет | Референс | Что |
|---|---|---|
| Kinetic Blue | риелтор-парень | мелкие слова оранжевым строчными, главное — огромное голубое капсом, строки вплотную, снизу + blur |
| Kinetic Orange | то же | белые слова + оранжевый акцент |
| Editorial | риелтор-девушка | мелкий белый текст + огромная фиолетовая антиква Didone капсом, blur |
| Editorial Italic | то же | курсивная антиква белым + акцент жирной антиквой |
| Invert | риелтор-парень (инверсия) | белый текст в режиме Difference: инвертирует кадр под буквами, blur-pop |
| Mix Colors | парень на набережной | слова ступенькой, главные крупные и каждое своего цвета по кругу (синий/красный/зелёный/оранжевый) |
| Pop Words | девушка-интервью | по одному слову по центру белым, выделенные — розовый жирный курсив |
| Reels Glow | ремонт в Дубае | белый мелкий текст в 1–2 строки, акцент красным со свечением, pop |
| NOIR Red | доктор | одно слово, красная антиква, жёсткая смена |

Шрифты в пресетах — бесплатные Google Fonts (Montserrat, Inter, Bodoni Moda / Playfair Display)
с запасными: SF Pro, Segoe UI, Arial, Georgia, Times (берётся первый найденный в системе). Для точного вида установите:
https://fonts.google.com/specimen/Montserrat , /Inter , /Bodoni+Moda , /Playfair+Display.
Шрифты в оригинальных роликах не определены точно — пресеты передают характер, а не копируют пиксель в пиксель.

Пока не сделано из референсов: плашка под числом («58K»), градиентная заливка,
пословная смена цвета внутри строки при произнесении, текст за человеком (нужна ротоскопия).

## Примеры стилей

`*.mp4` в корне — референсы. `1774639922519426331.mp4`: одно слово, капс, узкая контрастная антиква,
красный, верх кадра, жёсткая смена; текст местами за головой героя (маска — позже отдельно).
