# NOIR CAPTIONS

Локальный генератор анимированных субтитров для Adobe After Effects.
Распознавание речи на своём компьютере, без платных API, результат — редактируемые текстовые слои AE.

## Статус

| Этап | Что | Статус |
|---|---|---|
| 0 | Архитектура | [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) |

## Установка (Windows, один раз)

1. **Python 3.12** — https://www.python.org/downloads/ (при установке галочка *Add python.exe to PATH*).
2. **Движок распознавания** — в PowerShell из папки проекта:
   ```
   powershell -ExecutionPolicy Bypass -File recognition\setup_windows.ps1
   ```
   Создаст `.venv` внутри проекта и поставит faster-whisper (+ CUDA-библиотеки для NVIDIA).
   Модель не качает. В конце должно быть `CUDA устройств: 1`.
3. **Панель в AE** — PowerShell **от имени администратора**, из папки проекта:
   ```
   powershell -ExecutionPolicy Bypass -File scripts\install_panel.ps1
   ```
   (или вручную скопируйте `ae\NOIR Captions.jsx` в
   `C:\Program Files\Adobe\Adobe After Effects <версия>\Support Files\Scripts\ScriptUI Panels\`)
4. AE → `Edit → Preferences → Scripting & Expressions` → включить
   **Allow Scripts to Write Files and Access Network** (нужно, чтобы запускать Python; в сеть панель не ходит).
5. Перезапустить AE → `Window → NOIR Captions.jsx`. Панель пристыковывается как любая другая.

После `git pull` переустанавливать панель не нужно — она грузит код из папки проекта
(путь к ней спросит один раз).

## Работа

1. **Речь**: выделите в таймлайне слой со звуком (аудио или видео) → «Распознать речь».
   Распознаётся только видимая часть слоя. AE не зависает — статус и прогресс в панели.
   Первый запуск модели спросит разрешение на скачивание (large-v3 ≈ 3 ГБ, один раз).
2. **Текст**: исправьте ошибки. Одна строка = одна фраза; слова правьте внутри строк —
   тайминги сохранятся. Можно сохранить/открыть JSON, чтобы не распознавать заново.
3. **Стиль**: шрифт (поиск по установленным; или «Взять стиль с выделенного текстового слоя»),
   размер, цвет, обводка, КАПС, позиция, сколько слов на экране.
4. **Анимация**: появление и исчезновение отдельно (Fade, Pop, Punch, снизу/сверху/слева/справа, Zoom), длительности, сдвиг.
5. **Создать субтитры** — слои `NOIR · …` (зелёная метка). Повторное создание заменяет только их.
   Отмена — один `Ctrl+Z`. Если аудиослой сдвинуть после распознавания — субтитры встанут по новому месту.

### Язык
По умолчанию **Русский**. Внимание: если в ролике английская речь, а язык стоит «Русский»,
модель **переводит** её на русский (проверено). Для англ./смешанных роликов выбирайте «Авто» или «English».

## Тесты

```
node tests/run_tests.js
```
91 тест на имитации AE: группировка, правки текста, все сочетания анимаций (ключи не выходят
за слой), повторная генерация, шрифты, панель. Сквозной тест с настоящим Python:
```
set NOIR_PYTHON=.venv\Scripts\python.exe
set NOIR_MEDIA=C:\path\to\clip.mp4
node tests/run_tests.js
```
Имитация не заменяет проверку в настоящем AE.

## Известные ограничения

- Слой-прекомпозиция, Time Remap и обратная скорость пока не поддерживаются (будет понятная ошибка).
- Многословные группы — один слой на группу; пословное появление внутри группы — следующий шаг.
- Проверка наличия шрифта и список шрифтов — только AE 24+; в старых версиях — ввод PostScript-имени.
- Если имя пользователя Windows на кириллице — возможны проблемы с путём к временной папке (сообщите).
