# NOIR Captions — HTML-панель (CEP), разработка на Windows

С версии 0.30 это единственная панель. Старая ScriptUI-панель и скрытая «модель» внутри HTML удалены: интерфейс полностью свой, логика — в хост-API `ae/noir/app.jsx`.

## Как устроено

- `cep/index.html` подключает модули: `i18n.js` (RU/EN), `icons.js` (иконки Lucide), `theme.js` (тема AE), `host.js` (очередь запросов к AE), `ui.js` (поля, привязанные к настройкам), `wheel.js` (радиальное меню: кнопка-шар, правая кнопка, Пробел), `assistant.js` (помощник), `app.js` (вкладки Текст / Стиль / Правка / Настройки).
- Готовность компьютера: `setup.check` проверяет движок (`.venv` с faster-whisper), модель (кеш Hugging Face), доступ к файлам (пробная запись) и шрифты стиля. «Установить» и «Скачать» (`setup.engine`, `setup.model`) пишут `.cmd` во временную папку и открывают его в видимом окне — прогресс pip и скачивания виден там; панель перепроверяет каждые 5 с (до 20 минут) и при возвращении фокуса.
- Тайминг слов: `word.time` меняет начало/конец слова выбранной фразы (соседи уступают, минимум 40 мс, порядок сохраняется, отмена — «Отменить правку»), `word.seek` ставит время AE на слово. Изменённая фраза помечается к обновлению.
- Превью стилей в галерее — Web Animations API в самой панели (появление, исчезание, по буквам, караоке), без рендера в AE.
- Каждое действие — вызов `NoirHost.call(op, args)` → `NOIR_CEP.call` в `cep/host/bridge.jsx` → `app.call(op, args)`. Ответ несёт новое состояние; панель перерисовывает только изменившееся. Без действий пользователя панель к AE не обращается; опрос раз в 0.8 с идёт только во время распознавания и поиска лица.
- Поле с настройкой знает свой путь (`style.base.size`, `quick.position`…). Хост принимает только пути из белого списка и приводит значения к допустимым.
- Текст редактора уходит в AE через 350 мс после ввода или при уходе из поля. Пустой (только что построенный) редактор текст в AE не перезаписывает.
- Тема: фон панели берётся из AE (`appSkinInfo.panelBackgroundColor`), поверхности и текст вычисляются от него, смена темы AE применяется сразу. Акцент один — синий с белым.
- Дизайн-токены в начале `cep/style.css`: шрифт Inter (OFL, в `cep/fonts`), три размера текста (11/12/15), сетка 8 pt, анимации 160 мс ease-out. Старый Chromium в AE не знает `color-mix()`, `inset`, свойство `translate` — они не используются.

## Подключение

Закройте AE. В PowerShell из папки проекта:

```powershell
git pull --ff-only
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install_cep_dev.ps1
```

Скрипт копирует `cep/` в `%APPDATA%\Adobe\CEP\extensions\NOIRCaptions`, записывает путь к проекту, включает `PlayerDebugMode=1` для CSXS.11–14 (нужно неподписанному расширению разработки) и удаляет загрузчик старой ScriptUI-панели из AE, если найдёт (для папки Program Files может потребоваться запуск от администратора — скрипт скажет). Прежняя копия расширения сохраняется в `%LOCALAPPDATA%\NOIR Captions\cep-backups\`.

Откройте **Window → Extensions (Legacy) → NOIR Captions** (в русской версии — Окно → Расширения (устаревшие)).

Изменения в `ae/noir/*.jsx` читаются из папки проекта — достаточно закрыть и открыть панель. Изменения в `cep/` — снова запустить скрипт и перезапустить AE.

## Проверки

```
node tests/run_tests.js        логика генератора и инструментов
node tests/test_app.js         хост-API и мост
node tests/test_cep_browser.js панель в Chromium против настоящего хоста на имитации AE
node tests/check_es3.js        код хоста без синтаксиса новее ES3
```

Браузерный тест нужен Playwright с Chromium (только разработчику). Он проверяет: загрузку, отсутствие запросов в покое, блок готовности и кнопку установки, распознавание с опросом и его остановку, правку текста, таймлайн слов (перетаскивание края, клик, двойной клик, клавиши), создание с замечаниями, превью и выбор стилей, правку, расширенный режим, светлую тему и английский, радиальное меню (без наложений во всех секторах), план помощника, узкую панель 300 px, отсутствие наложений текста и иконок на всех вкладках при 4 ширинах, отсутствие ошибок JS. Настоящие слои, шрифты и CEP проверяются только в After Effects на Windows.
