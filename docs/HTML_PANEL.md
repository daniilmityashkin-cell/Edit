# NOIR Captions · HTML — разработка, Windows

Новая HTML/CEP-панель использует обычную браузерную прокрутку. Кнопка создания, статус, дополнительные настройки и строка вкладок находятся вне прокручиваемого содержимого и остаются сверху. Колесо в любой части панели, включая поля, кнопки и шапку, прокручивает содержимое выбранной вкладки. SFX по-прежнему добавляются только вручную.

## Почему другой тип панели

В используемом на Windows ScriptUI события `mousewheel` / `wheel` не доходят до зарегистрированных обработчиков. Сам нативный ползунок обрабатывает колесо отдельно. Повторная регистрация обработчиков это не исправляет. HTML устраняет эту зависимость от ScriptUI.

Основной экран сокращён до трёх шагов: видео, текст, стиль. Настройки устройства, дополнительные правки текста и точная настройка шрифта раскрываются по необходимости. Цвета, раскладка, анимация и ручной SFX доступны через меню «Настройки» справа.

HTML не дублирует бизнес-логику: `cep/host/bridge.jsx` создаёт прежнюю панель в скрытом режиме, передаёт значения контролов компактному HTML-интерфейсу и вызывает те же обработчики кнопок. Распознавание, правки, пресеты, Python и генератор слоёв остаются прежними. В браузере отображается только представление, а его опрос передаёт изменившиеся значения без пересоздания полей и потери курсора.

## Подключение для разработки

Закройте AE. В PowerShell:

```powershell
Set-Location 'C:\Users\danii\edit'
git pull --ff-only origin noir-captions-stage1
if ($LASTEXITCODE -ne 0) { throw 'Обновление остановлено.' }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install_cep_dev.ps1
if ($LASTEXITCODE -ne 0) { throw 'Не удалось скопировать HTML-панель.' }
```

Скрипт копирует файлы из `cep/` в `%APPDATA%\Adobe\CEP\extensions\NOIRCaptions` и записывает путь к проекту. Это не EXE-установщик, системный Python не меняется, администратор не нужен. Существующая копия расширения сохраняется в `%LOCALAPPDATA%\NOIR Captions\cep-backups\`.

Для неподписанного расширения разработки скрипт включает пользовательский параметр Adobe `PlayerDebugMode=1` в `HKCU\Software\Adobe\CSXS.11`…`CSXS.14`. Эти настройки не являются частью будущей коммерческой сборки.

Перезапустите AE и откройте **Window → Extensions (Legacy) → NOIR Captions · HTML**. В русской локализации — **Окно → Расширения (устаревшие)**. Старую панель **Window → NOIR Captions.jsx** закройте: она остаётся ScriptUI-версией, её возможности колеса не изменились.

При дальнейших изменениях только JSX обычно достаточно перезапустить HTML-панель/AE, так как код читается из папки проекта. При изменениях `cep/` повторите команду копирования и перезапустите AE.

## Проверки

```powershell
node tests/run_tests.js
node tests/test_cep.js
```

Браузерный тест `node tests/test_cep_browser.js` требует Playwright и Chromium в среде разработки тестов (они не нужны пользователю AE). В тесте проверяются реальные события колеса, неизменность положения вкладок, прокрутка вверх и вниз, отсутствие случайной смены пункта списка и ошибок JavaScript. Мост проверяется на имитации API AE. Установка CEP, загрузка моста и операции с настоящими слоями всё ещё требуют проверки в реальном After Effects на Windows.

Для проверки на Windows: открыть именно HTML-панель, уменьшить её высоту, перейти к стилям, прокрутить колесом над списком шрифтов и шапкой в обе стороны; вкладки не должны перемещаться. Затем проверить загрузку JSON, редактирование и создание субтитров, распознавание на существующем Python и ручное добавление SFX.

Поддержка заявлена для AE 2024+ с доступным CEP / Extensions (Legacy). Если раздел отсутствует или панель не появляется, нужны номер версии AE и вывод скрипта копирования — браузерный тест этого не подтверждает.

## Примеры стилей без засорения проекта

На странице «Стиль» видеопример проигрывается по наведению только при наличии подходящего исходного ролика с уже встроенными субтитрами. Сейчас подключён проверенный референс `1774639922519426331.mp4` к стилю NOIR Red: трёхсекундный беззвучный фрагмент и его постер в `cep/media/noir.*`. Оригинал не меняется. Прочие ролики без субтитров не используются, демонстрационный текст поверх видео не рисуется.

Для остальных стилей показаны статические карточки с названием и пометкой «Без видеопримера». Их соответствующие ролики с субтитрами ещё нужно предоставить и сопоставить со стилями. Наведение и выбор стиля не создают ни слоёв, ни композиций.

«Шрифт и точная настройка» содержит применение шрифта к выделенным слоям или ко всем NOIR-субтитрам. «Управление проектом → Удалить старые NOIR-превью» удаляет созданные прежней версией отдельные композиции с именами `NOIR Preview · …` и `NOIR · Галерея стилей`. Перед удалением есть подтверждение, композиции с непустым `usedIn` пропускаются, действие можно отменить через Ctrl+Z. Рабочие композиции с обычными именами не затрагиваются.

Прокрутка HTML ограничена реальной высотой видимых элементов. Скрытые вкладки и свёрнутые настройки не добавляют пустую высоту, вкладки находятся вне прокручиваемой области. Никакая прокрутка за последний блок не предусмотрена.
