# NOIR Captions · HTML — разработка, Windows

Новая HTML/CEP-панель использует обычную браузерную прокрутку. Кнопка создания, статус, дополнительные настройки и строка вкладок находятся вне прокручиваемого содержимого и остаются сверху. Колесо над полями, кнопками и шапкой прокручивает содержимое выбранного раздела; над многострочным текстом сначала прокручивается сам текст. SFX по-прежнему добавляются только вручную.

## Почему другой тип панели

В используемом на Windows ScriptUI события `mousewheel` / `wheel` не доходят до зарегистрированных обработчиков. Сам нативный ползунок обрабатывает колесо отдельно. Повторная регистрация обработчиков это не исправляет. HTML устраняет эту зависимость от ScriptUI.

Основной экран сокращён до трёх шагов: видео, текст, стиль. Настройки устройства, дополнительные правки текста и точная настройка шрифта раскрываются по необходимости. Цвета, раскладка, анимация и ручной SFX доступны в боковой панели «Настройки» справа.

HTML не дублирует бизнес-логику: `cep/host/bridge.jsx` создаёт прежнюю панель в скрытом режиме, передаёт значения контролов компактному HTML-интерфейсу и вызывает те же обработчики кнопок. Распознавание, правки, пресеты, Python и генератор слоёв остаются прежними. В браузере отображается только представление, а его опрос передаёт изменившиеся значения без пересоздания полей и потери курсора.

## Подключение для разработки

Закройте AE. В PowerShell:

```powershell
Set-Location 'C:\Users\danii\edit'
git pull --ff-only origin noir-captions-stage1
if ($LASTEXITCODE -ne 0) { throw 'Обновление остановлено.' }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install_cep_dev.ps1
if ($LASTEXITCODE -ne 0) { throw 'Не удалось скопировать HTML-панель.' }
```

Скрипт копирует файлы из `cep/` в `%APPDATA%\Adobe\CEP\extensions\NOIRCaptions` и записывает путь к проекту. Это не EXE-установщик, системный Python не меняется, администратор не нужен. Существующая копия расширения сохраняется в `%LOCALAPPDATA%\NOIR Captions\cep-backups\`.

Для неподписанного расширения разработки скрипт включает пользовательский параметр Adobe `PlayerDebugMode=1` в `HKCU\Software\Adobe\CSXS.11`…`CSXS.14`. Эти настройки не являются частью будущей коммерческой сборки.

Перезапустите AE и откройте **Window → Extensions (Legacy) → NOIR Captions · HTML**. В русской локализации — **Окно → Расширения (устаревшие)**. Старую панель **Window → NOIR Captions.jsx** закройте: она остаётся ScriptUI-версией, её возможности колеса не изменились.

При дальнейших изменениях только JSX обычно достаточно перезапустить HTML-панель/AE, так как код читается из папки проекта. При изменениях `cep/` повторите команду копирования и перезапустите AE.

## Проверки

```powershell
node tests/run_tests.js
node tests/test_cep.js
```

Браузерный тест `node tests/test_cep_browser.js` требует Playwright и Chromium в среде разработки тестов (они не нужны пользователю AE). В тесте проверяются реальные события колеса, неизменность положения вкладок, прокрутка вверх и вниз, отсутствие случайной смены пункта списка и ошибок JavaScript. Мост проверяется на имитации API AE. Установка CEP, загрузка моста и операции с настоящими слоями всё ещё требуют проверки в реальном After Effects на Windows.

Для проверки на Windows: открыть именно HTML-панель, уменьшить её высоту, перейти к стилям, прокрутить колесом над списком шрифтов и шапкой в обе стороны; вкладки не должны перемещаться. Затем проверить загрузку JSON, редактирование и создание субтитров, распознавание на существующем Python и ручное добавление SFX.

Поддержка заявлена для AE 2024+ с доступным CEP / Extensions (Legacy). Если раздел отсутствует или панель не появляется, нужны номер версии AE и вывод скрипта копирования — браузерный тест этого не подтверждает.

## Примеры стилей без засорения проекта

На странице «Стиль» видеопример проигрывается по наведению только при наличии подходящего исходного ролика с уже встроенными субтитрами. Сейчас подключён проверенный референс `1774639922519426331.mp4` к стилю NOIR Red: трёхсекундный беззвучный фрагмент и его постер в `cep/media/noir.*`. Оригинал не меняется. Прочие ролики без субтитров не используются, демонстрационный текст поверх видео не рисуется.

Для остальных стилей показаны статические карточки с названием и пометкой «Стиль». Их соответствующие ролики с субтитрами ещё нужно предоставить и сопоставить со стилями. Наведение и выбор стиля не создают ни слоёв, ни композиций.

«Настройки → Шрифт» содержит применение шрифта к выделенным слоям или ко всем NOIR-субтитрам. «Настройки → Проект → Удалить старые NOIR-превью» удаляет созданные прежней версией отдельные композиции с именами `NOIR Preview · …` и `NOIR · Галерея стилей`. Перед удалением есть подтверждение, композиции с непустым `usedIn` пропускаются, действие можно отменить через Ctrl+Z. Рабочие композиции с обычными именами не затрагиваются.

Прокрутка HTML ограничена реальной высотой видимых элементов. Скрытые вкладки и свёрнутые настройки не добавляют пустую высоту, вкладки находятся вне прокручиваемой области. Никакая прокрутка за последний блок не предусмотрена.


## Интерфейс 0.10

[Снимок интерфейса 0.10](images/html-panel-0.10.png) — Chromium, тестовые данные и имитация API AE.

- Три раздела «Видео / Текст / Стиль» закреплены вместе с главным действием и статусом. Качество, устройство и словарь перенесены в настройки справа.
- Настройки имеют независимую прокрутку. На ширине от 760 px они стоят рядом с основным разделом, на меньшей ширине открываются поверх него. Закрытие — крестик, фон или Escape; клавиатурный фокус остаётся внутри узкой панели.
- Главное действие: распознавание на странице видео, создание после загрузки текста, обновление текущей фразы после создания слоёв с метками источника. «⋯ → Обновить все фразы» выполняет полную генерацию; «Настройки → Проект → Заменить старые» управляет заменой.
- Выделение слова или нескольких слов одной строки открывает «Акцент / Перенос / Разделить». Действия также доступны в меню «Правки ⋯» для слова под курсором. Ctrl+Shift+A — акцент. Тайминги сохраняются при прежнем количестве слов; изменение количества слов перераспределяет время по длине слов.
- Курсор в другой строке меняет текущую фразу для обновления. Стрелки и список фраз также перемещают время композиции. «Правки ⋯» содержит отмену правки кнопками, сохранение результата и сброс; для обычного набора используется стандартная отмена в текстовом поле.
- Последние шрифты расположены первыми в разделе шрифтов. Избранное отмечается звездой на карточке. Названия встроенных карточек больше не содержат служебных номеров референсов.
- Автоматическая проверка показывает предупреждения в панели и рядом с полем; ссылки открывают шрифт, фразу или положение. До исправления или явного «Продолжить с замечаниями» слои не меняются. При изменении проверенных параметров продолжение требует новой проверки. Безопасная область — приблизительная оценка неподвижного текста, а не точный расчёт шрифта, эффектов или анимации.
- Свечение статическое; переходы занимают 120–200 мс. Учитывается `prefers-reduced-motion`: переходы и автоматическое воспроизведение отключаются. Видеопримеры проигрываются по одному, останавливаются при уходе курсора, смене раздела, скрытии/потере фокуса панели. Полный кадр сохраняется, встроенные субтитры не обрезаются.
- Колесо над редактором сначала прокручивает текст, а у границы — основную панель. Над настройками прокручивается их содержимое. Ни один список или числовое поле не меняет значение от колеса.
- SFX добавляются только отдельной ручной командой в «Настройки → Звук · вручную». Основная кнопка их не добавляет.

Браузерные сценарии дополнительно проверяют боковую панель на 880 px и наложение на 320 px, клавиатуру, выделение слов, отправку последних правок перед генерацией, сохранение остальных слоёв при обновлении одной фразы, переход по времени и вложенную прокрутку. Проверка выполняется в Chromium с имитацией API AE; она не заменяет запуск CEP в настоящем After Effects.

## Исправления 0.10.1

В простое HTML больше не вызывает `evalScript` по таймеру. Обращения к AE выполняются по действию пользователя и раз в секунду во время распознавания. Это устраняет постоянные фоновые входы в движок скриптов, способные вызывать индикатор занятости курсора. Снимок состояния также больше не перестраивает нативную строку вкладок. Исчезновение индикатора в настоящем AE требует проверки на Windows.

Видимость полей HTML отделена от видимости скрытых страниц ScriptUI; явно переключаемые группы анимации и инструментов сохраняют свою видимость. Уменьшены шапка, отступы и карточки, убраны декоративные вводные блоки; язык и качество находятся рядом на основном экране. Длинные списки остаются прокручиваемыми: вместить все настройки одновременно в маленькую панель без потери читаемости нельзя.

## Компактность и отзывчивость 0.13.0

- Шрифт интерфейса — Open Sans, локальный WOFF2 с кириллицей. 280 520 байт вместо 532 636 байт исходного TTF (на 47% меньше). Лицензия и источник — `cep/fonts/`. Шрифты самих субтитров определяются стилем.
- Преобладает чёрный градиент. Боковая полоса уже, настройки стоят рядом с основными разделами, убраны повторные пояснения и подзаголовок. Уменьшены отступы, высота карточек и шапки.
- Переключение основных разделов выполняется в HTML без `evalScript`. Новое распознавание или загрузка другого JSON автоматически открывает редактор по номеру версии данных, даже если нативная вкладка уже была выбрана раньше.
- В простое нет периодических вызовов AE или DOM-перерисовок. Опрос раз в секунду планируется только при активном распознавании и останавливается по завершении или при скрытии панели. Уведомления и статус успеха закрываются одноразовыми таймерами.
- Скрытая ScriptUI-модель не рисует кнопки, образцы шрифта, вкладки и бегунки и не регистрирует обработчики перетаскивания скрытых числовых полей. Обычная ScriptUI-панель сохраняет эти обработчики.
- Соседние изменения одного поля в очереди объединяются в последнее значение, пока AE занят. Команды генерации, сохранения и прочие действия сохраняют порядок; последние правки отправляются перед ними. Проверен ввод при искусственной задержке ответа AE 1,2 с.
- Видеопримеры останавливаются при уходе за видимую область. Галерея при запуске показывает страницу с последним выбранным стилем.

Браузерная проверка подтверждает ноль фоновых обращений к AE и ноль DOM-изменений в простое; локальную навигацию; запуск/остановку опроса распознавания; загрузку Open Sans; сохранение последнего ввода при задержке моста; вложенную прокрутку; отсутствие горизонтального переполнения на 280 px. Мост и слои проверяются через имитацию API AE. Это не замер скорости настоящего After Effects или распознавания на компьютере пользователя.

## Правка готовых субтитров 0.14.0

- Субтитры нескольких аудиослоёв в одной композиции: «Заменить старые» удаляет только прежние субтитры того же слоя.
- Анимация сдвига появления/исчезания — текстовый аниматор «NOIR Move». У `Position` слоя нет ключей, поэтому текст можно перетаскивать в окне композиции; ручной сдвиг сохраняется при обновлении фразы.
- Раздел «Правка» (в ScriptUI — вкладка «4 · Правка»): область изменений, положение фраз, сдвиг стрелками, возврат на исходные места, анимация, стиль, удаление.

Проверка на Windows в AE:
1. Распознать слой A → создать субтитры. Распознать слой B (другой ролик или второй кусок того же видео) → создать. Субтитры A на месте.
2. Перетащить слово или фразу мышью и проиграть: анимация появления/исчезания идёт от нового места.
3. Изменить текст фразы → «Обновить фразу»: фраза остаётся там, куда её сдвинули.
4. «Правка»: «Внизу», стрелки, «Вернуть на исходные места», смена анимации на «Снизу вверх» — субтитры другого видео не меняются. Ctrl+Z отменяет каждое действие одним шагом.
5. Анимации «Снизу», «Слева», Whip, Blur ↑ визуально совпадают с прежними (сдвиг теперь аниматором текста).
