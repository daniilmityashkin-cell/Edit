# Помощник NOIR: ИИ на вашем компьютере, работа с текстом и «не закрывать лицо»

Помощник открывается из центра радиального меню (кнопка-шар слева вверху, правая кнопка мыши или Пробел → клик по центру).
Он всегда сначала показывает план или «было → стало»; After Effects меняется только после «Применить». Простые просьбы он понимает сам («поставь внизу», «крупнее на 15», «появление pop»,
«сдвинь раньше на 0.3», «не закрывай лицо»). Просьбы своими словами обрабатывает **языковая модель, которая работает у вас**
через Ollama: бесплатно, без интернета (после скачивания модели), видео и тексты никуда не отправляются.

## Подключить модель (один раз)
1. Установите Ollama: https://ollama.com/download (Windows).
2. В терминале: `ollama pull qwen2.5:7b` (≈4,7 ГБ; для видеокарты с 8 ГБ и больше). Для слабого компьютера — `ollama pull qwen2.5:3b`.
3. В панели: шар → «ИИ-модель на этом компьютере» → «Проверить подключение». Справа вверху у помощника появится «ИИ: имя модели».

Если помощник пишет «ИИ не ответил» из-за запрета запросов (CORS), разрешите их Ollama и перезапустите её:
```
setx OLLAMA_ORIGINS "*"
```

## Работа с текстом
| Просьба | Без ИИ | Тайминги |
|---|---|---|
| «убери слова-паразиты» (ну, ээ, эм, типа, короче, как бы, um, uh, you know…) | да | у остальных слов — точно те же; фраза из одних паразитов остаётся |
| «добавь эмодзи» | да (по словарю ключевых слов); с ИИ — модель выбирает слово | эмодзи приклеен к слову — не меняются. В AE эмодзи видны, если шрифт их поддерживает |
| «исправь ошибки в тексте» | нет | принимаются только строки с тем же числом слов — тайминги точные; остальные пропускаются с пометкой |
| «переведи на английский» (en, ru, es, de, fr, it, pt, uk, kk, tr, zh, ja, ko, ar) | нет | начало и конец каждой фразы сохраняются, слова внутри распределяются по длине |
| «сделай динамичнее» / «спокойнее» | да | меняет силу и тип анимации, появление слов; если субтитры уже есть — обновляет их |

## Нарезка видео по речи
Помощник режет **сам слой видео** по распознанным словам: куски встают встык, субтитры пересоздаются под новое время.
Сначала AE считает план — «12 с → 7,4 с, убрать 4,6 с, кусков 6», видео меняется только после «Применить» (одна отмена Ctrl+Z в AE).

| Просьба | Что делает |
|---|---|
| «убери паузы», «убери паузы длиннее 1,5 секунды», «джамп кат» | вырезает тишину между словами длиннее порога (по умолчанию 0,5 с), у слов остаётся запас 0,08 с |
| «вырежи паразитов из видео» | вырезает из видео «ээ», «ну», «типа»… (без слова «видео» — только из текста) |
| «убери паузы и паразитов из видео» | оба сразу, одним планом |
| «оставь с 5 по 20 с» | оставляет только этот отрезок |
| «нарежь по фразам» | режет на куски по границам фраз, ничего не удаляя и не сдвигая |

Режется выделенный слой (или несколько — например, видео и отдельный звук), без выделения — распознанный слой, при повторной нарезке — куски
прошлой. Звуки, музыка и другие слои **не сдвигаются** — их нужно подвинуть самим. Слои с Time Remap не режутся. После нарезки
«прослушать фразу» и поиск лица продолжают брать кадры из исходного файла по карте кусков.

## Память
Всё хранится только на этом компьютере: `%APPDATA%\NOIR Captions\memory.json` (рядом с `noir.log`).
Посмотреть и удалить по одной записи — **Настройки → Память помощника → «Что помнит помощник»**, или спросить «что ты помнишь».

- **Исправления слов.** Когда вы создаёте субтитры, панель сравнивает распознанный текст с исправленным и запоминает замены слов,
  похожие на ошибку распознавания: опечатка или транслит («нуар → NOIR», «тикток → TikTok», «превет → привет»). Смысловые замены
  («сами → деньги») и переписанные строки не запоминаются. Исправление слова двойным кликом на таймлайне запоминается всегда.
  После следующего распознавания эти слова подставляются сразу (одна кнопка «Отменить правку» вернёт как было — и тогда панель
  запомнит, что эта замена не нужна), а их написание передаётся Whisper подсказкой. Выключается переключателем «Учиться на исправлениях слов».
- **«Запомни: …».** «запомни: субтитры всегда внизу» — заметка, которую видит ИИ-модель в каждой просьбе. Без ИИ заметки не применяются.
  «запомни: нуар пишется NOIR» / «запомни вместо сабы пиши субтитры» — сразу исправление слова.
- **Принятые ответы.** Если ИИ предложил план и вы нажали «Применить», такая же просьба в следующий раз выполняется сразу из памяти
  (с пометкой «из памяти», план всё равно показывается) — даже без ИИ. Последние принятые ответы ИИ видит как примеры «как вам нравится».
- **«Забудь …»** удаляет записи, где есть эти слова; «забудь всё» — стирает память после подтверждения.

## Любые просьбы скриптом (эксперимент)
Включается в помощнике: «ИИ-модель на этом компьютере» → **«Любые просьбы — скриптом»** (по умолчанию выключено). Тогда, если готовой
команды нет, ИИ пишет скрипт ExtendScript для AE: «добавь красную плашку под всем», «раскрась все текстовые слои в жёлтый», «поставь
маркеры через каждые 2 секунды». Начните просьбу с «скрипт:», чтобы сразу писать код.

- Код **показывается до запуска**; выполняется только после «Применить», одной отменой (Ctrl+Z в AE возвращает всё).
- AE сначала проверяет код и не запускает запрещённое: файлы и сеть, системные команды, eval, сохранение/закрытие проекта, рендер,
  импорт, окна и диалоги, служебные объекты панели, бесконечные циклы `while (true)`, синтаксис новее ES3. Если ИИ нарушил правила,
  его просят переписать один раз; если снова нет — кнопки «Применить» не будет.
- В коде доступны `comp` (активная композиция), `selected` (выделенные слои), `captions` (субтитры NOIR этого видео) и `log(...)`.
- Для кода лучше отдельная модель: `ollama pull qwen2.5-coder:7b`, затем выберите её в поле «Модель для скриптов».
- Принятый скрипт запоминается вместе с кодом: та же просьба потом выполняется сразу (код снова показывается).

**Честно:** это защита, а не песочница. Скрипт может, например, удалить слои или наделать лишнего — смотрите код перед запуском.
Если скрипт упал на середине, часть изменений могла примениться — Ctrl+Z. Зациклившийся хитро (не `while (true)`) скрипт может
подвесить AE — проверка ловит только очевидные бесконечные циклы. Маленькие модели ошибаются в API After Effects чаще, чем большие.

## Слои, маски, Roto Brush
- «выдели субтитры / акценты / фразу / видео / пульт», «сними выделение» — выделяет в таймлайне.
- «маска круг мягкая», «маска на нижнюю половину», «виньетка», «маска снаружи» — маска на выделенном слое (или на видео).
- «вырежи человека» — копия видео над субтитрами, открыта в окне слоя для Roto Brush. Обвести человека кистью нужно самому
  (Alt+W, затем Freeze): Roto Brush не управляется скриптами — это ограничение After Effects, а не панели.

Любая текстовая правка помощника отменяется одной кнопкой «Отменить правку» на вкладке «Текст». Текст модели передаётся строками
с номерами и разметкой (`*акцент*`, `~инверсия~`); ответ, в котором потерялись строки, не применяется.

Модель не получает доступа к вашим файлам: она видит только короткое «состояние» (размер кадра, стиль, где стоят субтитры, найденное лицо)
и возвращает список команд из фиксированного набора. Всё остальное, что она придумает, отбрасывается; удаление всегда спрашивает подтверждение.

## «Расположи красиво, чтобы лицо не загораживали»
Команда `avoidFace` берёт один кадр исходного видео (там, где стоит индикатор времени), ищет на нём лицо (OpenCV, на этом компьютере) и
переставляет субтитры: мелкий текст ниже лица, крупные акценты выше головы; если места мало — всё в более просторную полосу, при необходимости
текст уменьшается. По горизонтали ничего не двигается. Положение лица оценивается **по одному кадру**: если человек сильно двигается, поставьте
индикатор на характерный кадр и повторите. Предполагается, что видео занимает весь кадр композиции.

Нужен OpenCV 4 (ставится скриптом `recognition\setup_windows.ps1`; вручную):
```
.venv\Scripts\python.exe -m pip install "opencv-python-headless>=4.8,<5"
```
