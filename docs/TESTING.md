# Тестирование

## Автоматические (Node.js)
```
node tests/run_tests.js
```
Проверяют на имитации AE и ScriptUI (`tests/ae_mock.js`): JSON, правки текста, группировка, тайминги,
генератор слоёв и анимаций (ключи внутри слоя), правку выделенных слоёв, панель.
Сквозной тест с настоящим Python (распознавание → слои):
```
set NOIR_PYTHON=.venv\Scripts\python.exe
set NOIR_MEDIA=C:\путь\к\ролику.mp4
node tests/run_tests.js
```
Имитация AE **не заменяет** проверку в настоящем After Effects: она не рисует интерфейс и не знает
всех особенностей AE.

## Ручная проверка в AE (чек-лист)
- [ ] Панель открывается, вкладки переключаются, кнопка «Создать субтитры» сверху видна.
- [ ] «Распознать речь» на русском ролике: AE не зависает, статус меняется, текст появляется.
- [ ] Тайминги: слова появляются в момент произнесения (сравнить на 3–4 местах).
- [ ] Слой со звуком сдвинут/обрезан — субтитры встают правильно.
- [ ] «Создать субтитры» дважды: слои заменяются, свои слои остаются, `Ctrl+Z` откатывает запуск.
- [ ] Пресеты: Kinetic Stack, Editorial, Reels Glow, NOIR Red выглядят как задумано.
- [ ] Вкладка «Слои»: «Сделать акцентом» / «Обычным», «Шрифт → выделенным», применение анимации ко всем.
- [ ] Композиции с разным FPS и размером (1080×1920, 720×1280, 1920×1080).
- [ ] SFX: «Озвучивать при создании субтитров» — звуки встают на слова, слышны, не накладываются кашей; «Убрать SFX».
- [ ] SFX: «Озвучить выделенные слои», «В текущее время»; свои звуки из «Папка SFX» появляются после «Обновить список».
- [ ] Бегунки: зажать ЛКМ на числе и двигать — значение меняется плавно; Shift/Ctrl; клик открывает ввод; значения не выходят за границы.
- [ ] Функции → счётчик: «От/до/длит./шаг/интервал» меняют ход числа; формат (нули, тысячи, суффикс) верный; счётчик двигается по таймлайну вместе со слоем.
- [ ] Функции → зачёркивание: полоса ровно по ширине слова, вытирается в выбранную сторону, уходит вместе со словом; «Убрать зачёркивания».
- [ ] Функции → маска: видео видно внутри букв, оригинал скрыт; «Вырез»; «Убрать маски» возвращает текст.
- [ ] Анимация по буквам (Letters …, Type): буквы появляются по очереди слева направо; выход тоже.
- [ ] «Сделать акцентом» на слове из фразы: фраза перекладывается, анимация не ломается; «↻ Перекласть фразу».
- [ ] Шрифт отсутствует → предупреждение, слой создаётся.
