# Архитектура

## Поток данных

```
AE (ScriptUI, JSX)                    Python (локально)
 ├─ выбор аудиослоя → путь к файлу ──▶ recognize.py: ffmpeg → 16 kHz mono WAV
 │                                      → ASR → тайминги слов → captions.json
 ├─ ◀── чтение captions.json ──────────┘
 ├─ редактирование текста (позже)
 └─ генератор: JSON + пресет → текстовые слои + ключи
```

Связь — JSON-файлы во временной папке `%TEMP%\NOIR_Captions`:
`job_*.json` (задание) → Python в фоне (`start /min run_*.cmd`) пишет `status_*.json`
(этап, прогресс, pid) и `result_*.json`. Панель опрашивает статус через `app.scheduleTask`
раз в 0.5 с, поэтому AE не зависает; «Отмена» = `taskkill` по pid.
Пути к медиа передаются внутри JSON (UTF-8), а не в командной строке — кириллица не ломается.
Без сервера, без сетевых портов. Движок распознавания не знает про AE — его же
потом подключим к Premiere.

## Почему ScriptUI-скрипт, а не CEP/UXP

- `.jsx` запускается в любой версии AE без установки и подписи.
- CEP устаревает, UXP для AE ещё ограничен. Переход на панель — когда функции
  будут работать (этап 7). Логику генерации пишем отдельно от UI, чтобы её
  можно было перенести.

## Распознавание — кандидаты (проверяем на этапе 2, на вашем ПК)

| Движок | Плюсы | Риски |
|---|---|---|
| faster-whisper (large-v3 / turbo) | MIT; встроенные тайминги слов; ~4–5 GB VRAM в fp16 — влезает в 8 GB; хорошо с англ. вставками | на Windows нужны DLL cuBLAS/cuDNN (ставятся через pip); иногда «додумывает» текст на тишине/музыке |
| GigaAM (Сбер) | заточен под русский, по опубликованным замерам ниже WER на русском | нет готовых таймингов слов «из коробки» — нужен CTC-alignment; хуже с английскими словами; длинные файлы — через VAD |

План: стартуем с faster-whisper (быстрее всего к рабочему пайплайну с таймингами),
затем на одинаковых тестовых записях сравниваем с GigaAM и выбираем по
измеренным цифрам. Модели не скачиваются без вашего согласия.

## Формат данных (черновик, версия 1)

```json
{
  "schema": "noir-captions/1",
  "language": "ru",
  "source": { "file": "audio.wav", "offset": 0.0, "duration": 12.4 },
  "engine": { "name": "faster-whisper", "model": "large-v3" },
  "segments": [
    { "id": "s1", "start": 0.15, "end": 1.40,
      "words": [ { "text": "Привет,", "start": 0.15, "end": 0.48, "conf": 0.93, "edited": false } ] }
  ],
  "warnings": []
}
```
Время — секунды float от начала аудио; в AE пересчитывается с учётом
`layer.startTime` аудиослоя. В кадры не округляем до момента создания ключей.

## Главные риски

1. Тайминги слов Whisper на быстрой речи/музыке — нужна проверка на ваших роликах.
2. CUDA-зависимости на Windows.
3. Фоновый запуск + опрос статуса реализован; на Windows ещё не проверен в реальном AE.
4. Шрифты задаются PostScript-именем; проверка наличия надёжна только в AE 24+.

## Минимальные зависимости

- Этап 1: только After Effects.
- Этап 2: Python 3.11/3.12, ffmpeg, `faster-whisper` (+ `nvidia-cublas-cu12`, `nvidia-cudnn-cu12` для GPU). Всё бесплатно и в отдельном venv внутри проекта.

## Модули

| Файл | Что |
|---|---|
| `ae/NOIR Captions.jsx` | загрузчик для ScriptUI Panels; путь к проекту хранится в настройках AE |
| `ae/noir/core.jsx` | JSON, правки текста, группировка, пересчёт времени (без AE — тестируется в Node) |
| `ae/noir/generator.jsx` | слои, стиль, анимации входа/выхода (описаны данными: `ANIM_IN`/`ANIM_OUT`) |
| `ae/noir/recognizer.jsx` | выбор аудиослоя, запуск Python, опрос, отмена |
| `ae/noir/panel.jsx` | UI: вкладки Речь / Текст / Стиль / Анимация |
| `recognition/noir_recognize.py` | faster-whisper, тайминги слов, чистка таймингов, fallback GPU→CPU |
| `tests/` | мок AE + ScriptUI, тесты логики и сквозной тест с настоящим Python |
