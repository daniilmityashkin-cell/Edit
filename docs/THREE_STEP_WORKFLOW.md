# Трёхшаговая панель: проверка в After Effects

## Что изменено

- Версия 0.7.1: шапка с кнопкой создания, статусом и переключателем «Дополнительные настройки» закреплена сверху. Содержимое ниже прокручивается вертикальной полосой справа; расширять панель для доступа к нижним кнопкам не требуется. Колесо над текстовым полем прокручивает само поле; поддержка колеса над остальной панелью зависит от ScriptUI. Дополнительные вкладки расположены рядами по три.
- Основные шаги: «1 · Видео», «2 · Текст», «3 · Стиль». Остальные страницы открываются через «Дополнительные настройки».
- В редакторе выберите фразу. Клик по кнопке слова переключает акцент и выбирает слово для дальнейшей правки. Страницы по 12 слов позволяют работать с длинными фразами.
- «Исправить выбранное слово…» сохраняет его исходный интервал. «Отменить правку текста» отменяет последние 30 действий кнопками. Для прямого ввода в большом поле работает обычная отмена поля.
- «Перенос строки» переключает перенос перед выбранным словом (`↵`); «Разделить фразу» переключает новую группу перед словом (`|`). Число строк исходного редактора менять не требуется. Метки и инверсия сохраняются в JSON.
- `?` у слова означает уверенность модели ниже 0.65, если в результате есть поле `conf`. Это подсказка для проверки, а не доказательство ошибки.
- «Прослушать фразу» извлекает исходный звук выбранного сегмента без распознавания и открывает WAV в системном проигрывателе Windows. Движок запускается в фоне. Диапазон — до 120 секунд; воспроизведение скорости слоя не моделируется. При ручном `|` прослушивается весь выбранный исходный сегмент.
- На странице стиля: относительный размер 25–200%, положение сверху/по центру/снизу, спокойная или выразительная анимация. Значения сохраняются; выбор пресета сбрасывает модификаторы.
- «Превью фразы на видео» создаёт копию текущей композиции, убирает прежние NOIR-субтитры и NOIR-SFX только в копии, создаёт выбранную фразу с текущим стилем и задаёт рабочую область до пяти секунд. Для воспроизведения нажмите пробел / Num 0. Оригинал не изменяется; после просмотра копию можно удалить или отменить создание одним Ctrl+Z. Превью не является экспортом видео и не запускает распознавание.
- «Шрифт → выделенным слоям» действует на один или несколько выбранных текстовых слоёв. «Шрифт → всем субтитрам NOIR» действует только на сгенерированные NOIR текстовые слои текущей композиции. Шрифт берётся из выбранного режима «Обычные слова»/«Акцент». Остальные текстовые слои при применении ко всем не меняются.
- Новые пресеты: «Эксперт · Чистый», «Интервью · Чистый», «Reels · Акцент»: ограниченная ширина, умеренная анимация и контрастная тень. Короткие предлоги удерживаются со следующим словом при автоматическом переносе. Ручной перенос имеет приоритет.

## Проверки для разработчика

Из папки проекта, PowerShell:

```powershell
node tests/run_tests.js
node tests/check_es3.js
& .\.venv\Scripts\python.exe -m unittest discover -s tests -p test_preview_audio.py
```

Для этих изменений новые зависимости не нужны: используется существующий `av` и `numpy`.

## Обязательная ручная проверка на Windows

Автотесты работают на имитации AE. В настоящем AE нужно проверить:

1. Перезапуск AE, версия 0.7.1, три основных шага и переключатель дополнительных настроек над прокручиваемой областью. Уменьшить панель, протянуть ползунок справа до низа: кнопки переноса и прослушивания доступны, шапка остаётся на месте. Увеличить панель: ползунок ограничивается новым размером. Проверить все вкладки, в том числе дополнительные в узкой панели, и собственную прокрутку текстового поля.
2. Загрузка распознанного JSON; акцент кликом, правка слова, отмена, перенос и разделение. Сохранение и повторное открытие JSON с теми же таймингами.
3. Прослушивание фразы, включая путь с кириллицей. Исходное медиа должно оставаться на диске; WAV открывается в системном проигрывателе. Проверить сообщения об отсутствующем Python и ошибке декодирования.
4. Превью на исходном видео со сдвинутым/обрезанным аудиослоем. Проверить, что оригинальная композиция и её слои не изменились.
5. Применение шрифта к одному, нескольким и всем NOIR-слоям, включая отсутствие выделения для операции «всем». Проверить Ctrl+Z и отсутствие изменений у своих заголовков.
6. Новые стили на вертикальном и горизонтальном видео, длинных словах и двух строках. Визуальную готовность пресетов к продаже подтверждать только после этой проверки.

Ограничения: настоящие рендеринг, звук системного проигрывателя и ScriptUI проверяются на Windows с AE; облачные тесты их не подтверждают. Пословная правка сохраняет тайминг, а изменение количества слов в большом поле по-прежнему перераспределяет интервалы и выдаёт предупреждение при генерации.
