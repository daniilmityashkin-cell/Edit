# Если что-то не работает

Сообщения и логи: временная папка `%TEMP%\NOIR_Captions` (вставьте в адресную строку проводника).
В ней `log_*.txt` (вывод Python), `status_*.json` (на каком этапе распознавание), `result_*.json`.
В логи пишутся только технические сообщения, не содержимое ваших видео.

| Что видите | Причина и решение |
|---|---|
| «Папка проекта NOIR Captions не найдена» | В окне выбора папки впишите путь клона (например `C:\Users\<имя>\edit`) в поле «Папка» внизу. Если папка верная — в ней сделать `git pull` и убедиться, что есть `ae\noir\panel.jsx` |
| «Python не найден» | Не выполнен шаг 3 установки (`recognition\setup_windows.ps1`) или `.venv` удалён |
| «Модель … не скачана» | Скачайте командой `.venv\Scripts\python.exe recognition\download_model.py <модель>` (см. INSTALLATION, шаг 4) |
| AE «Не отвечает» при распознавании | Исправлено в версии 0.3+ (запуск Python больше не блокирует AE). Обновитесь (`git pull`). Если осталось — завершите `python.exe` в Диспетчере задач и пришлите `log_*.txt` и `status_*.json` |
| Окно AE «You are about to run the script… .vbs» | Нормально: AE спрашивает разрешение на запуск. Нажмите Yes или отключите «Warn User When Executing Files» (Preferences → Scripting & Expressions) |
| «CUDA устройств: 0» после установки | Обновите драйвер NVIDIA; без GPU выберите устройство «CPU» в панели |
| «Загрузка модели … (cuda)» висит дольше 2–3 минут | Нажмите «Отмена», запустите вручную `recognition\noir_recognize.py … --device cpu`, затем `--device cuda`, и пришлите вывод |
| Русская речь, а текст на другом языке / английская речь «переведена» на русский | Язык «Русский» заставляет модель писать по-русски. Для английских и смешанных роликов выберите «Авто» |
| Распознанного текста нет / «Речь не найдена» | В слое нет речи в видимом участке (распознаётся только видимая на таймлайне часть слоя) или слишком тихо / музыка |
| Распознан обрывок вместо всего ролика | Обрезан слой: распознаётся только видимая часть. Растяните слой или рабочую область |
| «Прекомпозиция или не файл», Time Remap, обратная скорость | Пока не поддерживаются: распознавайте исходный файл (видео/аудио) прямо в композиции |
| Шрифт не применился, предупреждение | Шрифта нет в системе: установите (Montserrat, Inter, Bodoni Moda — Google Fonts) или выберите другой во вкладке «Стиль» |
| Субтитры «как обычные» | Выберите пресет (не «свой»), «Слов на экране» 3–5, включите «Авто-акценты», установите шрифты пресета |
| Не вижу кнопки / нижняя часть панели обрезана | Кнопка «Создать субтитры» закреплена сверху. Растяните панель или стыкуйте её в более высокое место |
| Вкладки не помещаются по ширине | Растяните панель по ширине |
| Кириллица в пути (имя пользователя) | Пути передаются в UTF-8 через файл; если что-то не запускается — пришлите `log_*.txt` |
| Ошибка записи файла | Включите «Allow Scripts to Write Files and Access Network» (шаг 6) |

Дополнительно: `node tests\run_tests.js` — проверка логики (нужен Node.js).
